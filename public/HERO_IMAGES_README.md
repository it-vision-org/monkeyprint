# Hero Images for Store Themes

This project uses three default hero images for the store themes. Please add the following images to the `public` folder:

## Required Hero Images

### 1. hero1.png - Modern Professional Theme
- **Theme**: Theme 1 - Modern Professional
- **Recommended Size**: 280x280px or larger
- **Color Scheme**: 
  - Sky Blue: `#0ea5e9`
  - Blue: `#3b82f6`
  - Indigo: `#6366f1`
- **Style**: Clean, professional, premium product image
- **Suggested Content**: High-quality product photo with clean background

### 2. hero2.png - Vibrant Boutique Theme
- **Theme**: Theme 2 - Vibrant Boutique
- **Recommended Size**: 280x280px or larger (circular display)
- **Color Scheme**: 
  - Coral: `#fb923c`
  - Magenta: `#f472b6`
  - Purple: `#a855f7`
- **Style**: Fun, colorful, energetic product image
- **Suggested Content**: Vibrant product photo with playful elements

### 3. hero3.png - Elegant Dark Theme
- **Theme**: Theme 3 - Elegant Dark
- **Recommended Size**: 400x300px or larger (background image)
- **Color Scheme**: 
  - Deep Purple: `#8b5cf6`
  - Pink: `#ec4899`
  - Rose: `#f472b6`
- **Style**: Sophisticated, elegant, luxurious product image
- **Suggested Content**: Premium product photo with dramatic lighting

## Usage

These images are used as default hero images for each theme when:
1. No custom hero image is uploaded via theme customization
2. No store logo is available

The system will automatically fall back to these images to ensure the themes always have a hero image.

## Image Format

- Preferred format: PNG with transparency
- Alternative formats: JPG, WebP
- Ensure images are optimized for web use

## Creating Placeholder Images

Until you have proper product images, you can create placeholder images:
- Use online tools like Figma, Canva, or Adobe Photoshop
- Use the color schemes mentioned above
- Include your brand name or "Coming Soon" text
- Keep the design clean and on-brand
