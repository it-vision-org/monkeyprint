# Theme System Overhaul - Business & Features Plan

## Executive Summary

Transform the theme system from 3 static mockup themes to 3 fully customizable, dynamic themes that allow store owners to create unique, branded shopping experiences. Store owners will have complete control over their store's appearance through an intuitive customization interface.

---

## Current State

**What We Have:**

- 3 static themes that are essentially CSS variations
- No customization options
- Hardcoded content (titles, images, text)
- All stores with the same theme look identical
- Limited branding opportunities

**The Problem:**

- Store owners can't express their brand identity
- No way to differentiate stores visually
- Static content doesn't reflect store personality
- Limited creative control

---

## User Experience Flow

### Theme Selection

1. Store owner views 3 theme previews
2. Each preview shows the theme's personality and style
3. User selects theme that matches their brand
4. Can switch themes anytime with customization preserved where possible

### Customization Journey

1. **Overview:** See current theme and quick stats
2. **Colors:** Pick brand colors with live preview
3. **Hero:** Customize hero section with images and text
4. **Content:** Edit titles, descriptions, and messaging
5. **Images:** Upload and manage banners and images
6. **Layout:** Adjust spacing and grid preferences
7. **Typography:** Choose fonts and text styles
8. **Preview:** See changes in real-time on mobile and desktop

### Live Preview

- Real-time updates as user makes changes
- Mobile and desktop preview toggle
- Product mockups with actual store products
- Category previews
- Section previews
- No need to save to see changes
